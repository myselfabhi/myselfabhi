# Abhinav Verma

**Product engineer in New Delhi.** Full-stack engineer by day. The rest of the time, I’m building my own products.

I take products from idea to launch: scoping what to build, designing the interface, building the backend and shipping it to users. Most of my work is TypeScript end to end, with AI features where they genuinely help.
